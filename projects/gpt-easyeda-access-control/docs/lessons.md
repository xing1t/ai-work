# 失败经验与已知问题

以下来自 [原始交接第 7 节](original/PROJECT_HANDOFF.md)，是历史观察，不是本次重新触发或定位的问题。

|问题|经验与被替代路径|
|---|---|
|初版布局外形/丝印重叠|人工纠正后按真实几何重排；旧 layout_final 等命名不能决定最终版本|
|过孔创建但不导通|本机字段修正为 viaType=0、ruleName=null 后检查；其他版本需重新确认|
|外层 success=true、内层 applied=false|请求执行不等于工程接受写入；必须检查业务返回和回读|
|源尾部 PAD_NET 丢失|保留原生行分隔和尾换行，逐项核对 191 焊盘映射|
|动态覆铜 API 不兼容|历史 POUR/POURED 尝试被固定 FILL 路径替代；不能声称动态覆铜成功|
|无筛选删除文字使位号消失|修复后验收 56 位号可见；不能泛化删除|
|临时请求和回包覆盖|eda_last.json、日志及临时截图不作为稳定版本入口|
|名称暗示只读但有副作用|verify 脚本会写本地源，read_final 会 DRC 并保存；逐份阅读后再决定使用|

保留代表性写回与固定地铜脚本用于研究，其余失败中间产物未复制，原因逐条记录于归档映射。保留的 priority DSN/SES 仅属于过孔修正、SWD 收尾和地铜之前的布线阶段，已被最终源替代。

单位：历史 PCB API 坐标为 mil，mm=mil×0.0254；原理图使用其 API 的 10mil 单位。不能从规则显示 unit=mm 猜测原生字段单位。原理图 DRC 未闭环、电机未选型、原生备份未验证仍是当前已知问题。
