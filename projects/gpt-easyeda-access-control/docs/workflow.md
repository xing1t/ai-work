# 流程与人工检查点

本页描述历史流程和后续操作要求，本次未执行 EDA 操作。

|阶段|历史做法|人工检查点|
|---|---|---|
|需求|课程约束及用户决策整理|模块针序、电平、负载与验收标准|
|原理图|逐件放置、真实引脚回读、短引线及同名标签|型号封装引脚；标签真正连接；173 项对照不代替电气审查|
|PCB 准备|用户已创建并导入 56 器件|不能声称 AI 验证了从零导入全过程|
|布局|根据实际外形、丝印与焊盘重排|板边、螺丝、连接器插拔空间，不能只看铜间距|
|布线|关键电源/晶振优先，DSN/SES 本机计算后写回|实际网络和几何；布线器完成不代表 EDA 连接通过|
|收尾|过孔字段适配、SWD 缩短、固定地铜|变更后重算 FILL；检查业务 applied、回读和保存|
|验收|历史 PCB 严格 DRC 与预览|规则适用范围、焊盘基准、位号、装配及尚未完成的实测|

后续任何设计修改另行明确目标：先确认工程/文档、备份和修改范围，再小批操作、回读和人工检查。不能直接串联运行归档脚本。旧启动和布线命令仅记录在原交接第 5 节，依赖本机输入，未演练全新环境恢复。

当前仓库唯一建议的执行命令是在仓库根运行：

```powershell
python projects/gpt-easyeda-access-control/validation/verify_archive.py
```

验证范围仅为归档文件哈希、Markdown 相对链接、保存快照内容及暂存字节（若已暂存）；不运行历史脚本、不导入 EDA 模块、不访问网络、不修改源文件。复制或下载得到的新版本需另存并更新证据链。
