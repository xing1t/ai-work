# 密码门禁方案与成本估算

估算日期：2026-11-04。已通过本机桥服务重新读取“密码门禁”原理图及真实网表，确认板上56个元件。本次未修改EDA工程。

## 方案

5V外部稳压电源供电，经AP2112K-3.3为STM32F103C8T6及3.3V外设供电；电机、继电器、蜂鸣器使用5V。
外接4×4无源矩阵键盘，行列各4个GPIO；外接PIR，检测人员后点亮白光LED。
两个SRD-05VDC-SL-C继电器切换电机两端的极性，模拟开门和关门；AO3400A驱动线圈，SS14作钳位。
有源蜂鸣器用于密码错误报警。AT24C02D保存密码及有限条数的循环日志。
STM32内部RTC搭配32.768kHz晶体及CR2032备份；外接I2C OLED显示时间和日志。
8MHz晶体提供主时钟，SWD接口用于下载调试。15个电阻和16个电容均为0805。

功能目标：4位密码确认后正转5秒、等待10秒、反转5秒；30秒内连续两次密码错误报警，支持密码修改和掉电保存。上述行为需要后续固件实现。
